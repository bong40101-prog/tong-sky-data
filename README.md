# 통SKY 저장 달력 홈페이지

공개 홈페이지는 현재 검색 오류 안내만 표시합니다. 검색 페이지 수정본은 `web-source`에 보관하며, 사용자 요청 없이 `gh-pages/index.html`의 공지를 검색 화면으로 교체하지 않습니다.

## 최종 비운항 판정 V2

대한항공 유럽·미국만 적용합니다. 노선·방향·월을 각각 분리하고 원본 달력의 `awardCalendarFlags`, `legacyAwardFlags`, 원본 날짜 필드 순서로 표식을 읽습니다. 항공편·운항사·공동운항·운항요일표는 이 판정을 변경하지 않습니다.

- 해당 월의 동일 요일 전체에 이코노미 보너스·프레스티지 보너스·프레스티지 승급 표식이 모두 있으면 해당 날짜의 모든 표식을 제외합니다.
- 한 날짜라도 다르거나 미확인·누락이면 해당 요일 전체를 주황색 확인필요로 표시하고 유효한 원본 표식을 유지합니다.
- 원본 미확인은 미확인으로 유지합니다. 반대 방향이나 다른 월의 판정을 복사하지 않습니다.
- 판정 식별자는 `USER_ALL_WEEKDAYS_TRIPLET_V2`입니다. 표시 결과와 원본 좌석·수집 시각을 구분하며 원본 관측을 덮어쓰지 않습니다.

유럽·미국의 표시와 합계는 원본 달력에서 직접 계산해 기존 항공편·운항요일표 처리 단계를 생략합니다. 12월 18일 이후도 표시하며 캐나다를 포함한 그 외 대한항공 지역은 2026년 12월 17일 제한을 유지합니다. 아시아나의 조회 기간은 유지합니다.

## 조회 범위와 불러오기

대한항공·아시아나 모두 동북아·한국을 제외합니다. 지역·국가·도시 목록과 과거 저장 결과에 같은 필터를 적용합니다. 인천 등 국내 출발 공항으로 국제선을 조회하는 기능은 유지합니다.

대한항공은 남은 지역 문서를 읽으며, 아시아나는 합본 문서를 한 번 내려받은 뒤 제외 지역을 제거하고 유럽·미주·나머지 지역별로 검증·처리합니다. 현재 지역·처리 개수·진행률을 표시하고 모든 처리가 끝나야 100%가 됩니다. 취소·오류는 성공이나 좌석 없음으로 바꾸지 않으며 실패한 지역의 이전 자료만 유지할 수 있습니다.

이 홈페이지는 저장 자료의 조회 전용입니다. 항공사 검색·로그인·수집을 실행하지 않습니다. 새로운 자료는 앱의 공유 자료에 반영되며 원래 수집 시각을 유지합니다.

## 판정 기록

노선·방향·월·요일·일치 횟수·확인 날짜·사유·원본 수집 시각을 표시합니다. 브라우저에 최대 2,000건을 중복 없이 유지하며 V1 기록은 이전 기준으로 구분합니다. 저장이 차단된 환경에서는 메모리 기록을 유지합니다. JSON 다운로드와 배포 시점의 `dist/repeat-marker-audit.json`을 제공합니다.

## 검증

`npm test`로 자료·로더·모델·DOM 통합 검사를 실행합니다. V2 검사에는 실제 파리 2026년 12월 20·27일의 주황색과 원본 표식 유지, 13일 미확인, 2027년 2월 일요일 전체 표식 제외, 지역 제외, 아시아나 단계별 로딩과 기록 보존을 포함합니다. 비대상 지역의 운항 대조 엔진 검증은 별도로 유지합니다.
