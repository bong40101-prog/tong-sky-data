# 월별 반복 표식 제외 (2026-11-02)

대한항공 유럽·미국 노선에만 적용합니다. 원본 한 노선·방향·월의 달력에서 해당 요일의 모든 날짜(4회 또는 5회)에 이코노미 보너스·프레스티지 보너스·프레스티지 승급 표식이 모두 있을 때 그달의 해당 요일을 표시·합계에서 제외합니다. 두 주 반복만으로는 제외하지 않으며, 한 날짜라도 다른 표식·미확인·누락·중복이면 요일 전체를 주황색 확인필요로 표시하고 유지합니다. 다음 달이나 반대 방향으로 판정을 복사하지 않습니다.

공동운항편은 판정 대상에서 제외합니다. 항공편 상세가 있으면 직접 운항편의 표식만 판정에 사용하고, 운항·좌석 근거가 확인된 공동운항편의 표식은 계속 표시·합산합니다. 구형 합산 달력은 사용자 지정 추정 기준으로만 활용하며 실제 운항을 확정한 근거로 바꾸지 않습니다. 원본 상태·표식·수집 시각은 변경하지 않고 표시용 메타데이터를 덧붙입니다.

대한항공 유럽·미국은 월별 판정을 적용한 뒤 2026-12-18 이후도 공개합니다. 다른 대한항공 지역은 2026-12-17 제한을 유지합니다. 표시 범위를 적용하기 전에 원본 월 전체를 검사하므로 월말 날짜의 누락·다른 표식도 판정에 반영합니다. 홈페이지 상단에 공동운항 제외 공지를 표시하고 달력·날짜 상세에 추정 기준과 판정 날짜를 안내합니다. 이전 수정 중 공지와 직접·공동운항/프랑크푸르트 설명 문구는 삭제했습니다. 판정 기록 표에는 노선·방향·월·요일·일치 횟수·다른 날짜와 사유·원본 수집 시각을 표시합니다. 전체 월의 판정 스냅샷은 `dist/repeat-marker-audit.json`으로 보존합니다.

# 통SKY 조회 전용 홈페이지

## 운항요일 참고표

1.0.39는 제공된 운항요일 표를 `dist/timetable-reference.json`으로 함께 읽습니다. 노선 방향·실제 운항사·적용 시작/종료일을 따로 대조하고, 날짜별 일부 확인 구간과 출처 간 불일치 구간을 미확인으로 구분합니다. `DATES_ONLY`의 주간 요일 메타데이터는 비운항을 추정하는 데 사용하지 않으며 확인된 날짜 외에는 미확인입니다. 동일 운항사의 여러 편 중 운항 확인일이 하나라도 있으면 운항 참고로 표시하고, 모든 적용 규칙이 명시적으로 비운항일 때만 비운항 참고로 표시합니다.

이 표는 전체 운항사를 관측한 공식 주간 스케줄이나 좌석 정보가 아닙니다. 기존 항공편별 공식 조회 결과와 참고표가 충돌하면 해당 운항사 행에 `운항 일정 불일치 · 표식 제외`를 표시하고 그 행의 좌석 표식만 합계에서 뺍니다. 실제 공식 조회가 비운항으로 확인한 행은 그대로 유지합니다. 원본 좌석 관측·주간 스케줄·수집 시각은 변경하지 않으며, 참고표만으로 미확인 자료를 좌석 있음·좌석 없음·전체 비운항으로 확정하지 않습니다.

월별 달력 위에는 해당 월·방향에 적용되는 직접운항·공동운항 참고 일정을, 날짜 상세에는 실제 항공편 결과와 구분한 운항요일 참고 상태를 표시합니다. 인천↔프랑크푸르트 수·금·일 직접운항 규칙은 기존 사용자가 별도로 지정한 기준이며 참고표의 적용 기간을 확장하지 않습니다. 참고표를 불러오지 못해도 기존 좌석 자료와 공식 운항 대조 결과는 그대로 볼 수 있습니다.

추가 검사는 실제 참고표 로드, 부분 날짜·월 경계, 방향·운항사 분리, 공동운항 유지, 충돌 행 표식 제외, 원본 불변과 선택적 연결 실패를 검증합니다.

대한항공·아시아나 앱이 공개 저장소에 공유한 자료를 읽어 노선·날짜·좌석 표식으로 조회합니다. 항공사에 자동 조회하거나 자료를 쓰는 기능은 없습니다. 방문자는 로그인 없이 조회만 할 수 있습니다.

접속 시 두 항공사의 저장 문서 9개를 실제로 읽는 진행률을 표시하며 모두 확인한 뒤 메인으로 이동합니다. 없는 문서(404)는 저장 자료 없음으로 처리하고, 연결·검증 오류는 재시도 또는 불러온 자료로 보기 선택을 제공합니다. 실패를 좌석 없음으로 바꾸지 않습니다.

프레스티지/비즈니스 보너스·승급과 대한항공 퍼스트 합산 표식을 분리합니다. 달력의 회색은 미조회·미확인입니다. 원래 수집 시각을 유지하며 내려받은 시각으로 최신 자료처럼 표시하지 않습니다. 자료는 항공사별로 검증하고 압축 해제 용량·날짜 누락·잘못된 좌석 필드를 확인합니다.

## 검사

`npm install` 후 `npm test`로 순수 자료·로더·DOM 통합 검사를 실행합니다. 실제 공개 저장 자료를 입력으로 사용하며, 로딩 완료 대기·부분 실패·재시도·항공사 전환·검색·달력·원래 시각·링크를 검사합니다.

PC와 375px 콘텐츠 너비의 실제 브라우저에서 공개 자료 읽기, 시작 로딩→메인 전환, 날짜 상세 보기, 가로 넘침 없음과 상단 링크 배치를 확인했습니다. 시험용 iframe 페이지는 배포본에 포함하지 않습니다.

사이트 ID는 `.openai/hosting.json`에 유지합니다. 통시리즈와 롱숏레이더 버튼은 사용자가 지정한 기존 홈페이지로 연결합니다. 새 데이터는 앱이 수집해 공유해야 반영되며 이 사이트는 데이터 수집 작업을 실행하지 않습니다.

## 대륙·국가·도시 선택

대륙·지역 → 국가·지역 → 도시·공항을 순서대로 선택할 수 있습니다. 국가별 목록은 항공사별 공항 카탈로그를 기준으로 하며, 대륙을 바꾸면 국가·공항 선택을 초기화합니다. 항공사 변경 시 해당 항공사의 목록에 없는 선택은 해제합니다. 목록에 공항이 있어도 저장 자료가 없으면 미확인 상태로 안내하며 좌석 없음으로 바꾸지 않습니다. 상단 요약도 선택한 범위에 맞춰 집계합니다. 국가 분류 출처는 `docs/geography.json`에 있습니다. 신규 메타데이터가 이전 캐시에 가려지지 않도록 카탈로그 재검증을 적용했습니다.

총 36개 검사(기존 26개 + 분류·연동 10개)가 통과했습니다. 실제 브라우저에서 동북아시아→일본 공항 목록, 유럽→프랑스→파리 선택과 달력 표시를 확인했습니다.

## 등급별 날짜 수

노선 목록, 달력 위 집계, 날짜 칸은 모두 선택한 월·방향·좌석 조건과 시작/종료일의 교집합을 기준으로 합니다. 월 선택·이전/다음 달·가는/오는 편 변경 시 목록의 수량, 정렬, 표식 있는 노선 필터, 상단 요약을 함께 갱신합니다. 관측 날짜가 전혀 없는 월·방향은 미확인으로 처리하며, 선택 기간 밖의 날짜는 표식을 숨기고 기간 밖으로 표시합니다.

프레스티지 보너스·승급·퍼스트 합산을 분리하고, 아시아나는 비즈니스 보너스·승급만 제공합니다. 숫자는 잔여 좌석 수가 아닌 표식이 있는 날짜 수입니다. 한 날짜에 여러 유형이 겹치면 각 유형에 포함합니다. 퍼스트 원본은 합산 필드이므로 보너스와 승급으로 따로 추정하지 않습니다.

총 47개 검사로 유형 중복, 날짜 경계, 항공사 구분과 미확인/0일 구분을 확인했습니다. 로마 실제 저장 자료의 10~12월·양방향 6개 조합에서 목록 수량 = 달력 집계 = 활성 날짜 칸의 표식 수인지 검사합니다. 좌석 필터, 표식 있는 노선, 월 이동 및 부분 날짜 범위도 검증합니다.

## 방향별 전체 기간 수량

노선 카드에 선택한 시작일~종료일의 가는 편 전체·오는 편 전체를 나란히 표시합니다. 각 방향의 보너스·승급·퍼스트 합산을 따로 집계하고, 관측이 전혀 없는 방향은 미확인으로 표시합니다. 월이나 달력 방향을 바꾸어도 전체 기간 수량은 유지되며, 날짜 범위를 바꾸면 다시 집계합니다.

목록·상단 요약·정렬·표식 있는 노선 필터는 전체 기간과 양방향 자료를 사용합니다. 현재 달력에 자료가 없더라도 다른 월·방향에 저장 자료가 있는 노선은 유지합니다. 카드 아래 현재 달력 상자는 기존대로 오른쪽 달력과 동일한 월·방향·좌석 조건을 사용합니다. 총 50개 검사에서 로마 전체 기간(보너스 1/1일, 승급 2/4일), 월 전환 시 전체 합계 유지, 날짜 범위 변경, 한 방향 미확인, 아시아나 양방향 합계를 검증합니다.


## 지역별 시작 로딩과 판정 기록

아시아나는 저장 문서를 한 번 내려받은 뒤 유럽·미주 등 지역별로 검증·처리하며 현재 지역과 전체 진행률을 표시합니다. 100%는 항공사 자료와 운항 대조를 마친 뒤에만 표시합니다. 실패하거나 중단한 아시아나 문서는 일부만 반영하지 않습니다. 기존 자료 수집 시각과 왕복 방향을 보존합니다.

판정 기록은 사유·해당 날짜·원본 수집 시각을 포함하며 이 브라우저에 최대 2,000건을 중복 없이 유지합니다. 변경 전 판정도 함께 보관합니다. 저장이 차단된 브라우저에서는 현재 조회 기록과 JSON 내려받기가 가능합니다. 배포 시점 전체 유럽·미국의 판정도 repeat-marker-audit.json으로 보관합니다.

대한항공·아시아나 모두 동북아·한국 노선을 조회 대상에서 제외합니다. 지역·국가·도시 목록과 과거 저장 결과에도 같은 필터를 적용하고, 대한항공 해당 지역 문서를 요청하지 않습니다. 아시아나의 합본 저장 자료는 해당 지역을 제외한 뒤 지역별로 처리합니다.
