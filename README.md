# 통SKY 공개 달력 수집기

대한항공 로그인 없는 공식 보너스 좌석 현황을 브라우저 화면으로 읽는 개인용 앱의 수집기입니다. 계정·승객·예약·관심 검색·서명 키는 포함하지 않습니다.

- 매일 한국시간 09:01 (UTC 00:01) 예약 실행. GitHub 실행 지연과 수집 시간이 있어 완료 시각을 보장하지 않습니다.
- 출발 공항은 인천 ICN. 공식 지역 목록의 모든 공항을 대상으로 오늘부터 359일 뒤까지 걸친 모든 월을 조회합니다. 목록은 2026-10-29 공식 화면에서 확인했습니다. 해당 출발지의 직항 또는 모든 날짜 운항을 보장하는 목록은 아닙니다.
- 미주·유럽·동북아·동남아/서남아·대양주/괌·중앙아시아·중동/아프리카·국내. 조회는 순차 실행하며 각 노선·월 사이에 4초 기다립니다.
- 접근 제한, HTTP401/403/429, 보안 확인은 중단합니다. 우회나 토큰 복사, 내부 API 재현 호출을 하지 않습니다.
- 실패를 좌석 없음으로 저장하지 않습니다. 마지막 정상 결과를 보존합니다. 보너스·좌석승급과 정보 기준 시각을 구분합니다. 정확한 잔여 좌석 수와 여러 명 동시 예약은 확인할 수 없습니다.
- 자료는 `tong-sky-data` 브랜치의 `data/snapshots`, 지역별 진행률은 `data/regions`에 저장합니다. `completed/total`은 처리 수이며 성공 수와 미확인 수를 별도로 표시합니다.
- 지역당 작업을 10개 공항씩 나눠 작업 실행 한도 안에서 처리합니다. 모든 작업은 한 번에 하나만 실행됩니다.

## 검증
`node --test tong-sky/cloud/test.mjs`는 데이터 검증·날짜·실패 보존을 검사합니다. main 변경 시에는 실제 공식 페이지 2건을 수집하는 probe를 먼저 실행합니다. Actions에서 수동 실행의 `full`을 선택하면 전체 수집, `probe`는 소량 검증입니다.
